Three layouts for the inspector in 2026-10-07-ai-prompts-design.md, filled with real findings from the 2026-10-07 test runs. These are web approximations of SwiftUI: section headings are SectionLabel, buttons are standard small bordered buttons, and the panel sits in the existing .inspector, so take layout, hierarchy and copy from here, not pixel values. Clicking a row still jumps to the text in the editor, as now. Styles are inline because this is a single reference file, not app code.

Behaviour common to all three

  • Apply replaces the finding's exact text in the editor as one undoable step, then marks the row Applied. If the text has changed since the evaluation, Apply is disabled and the row says “Text has changed.”
  • Apply All appears on Corrections only, since suggestions are judgment calls.
  • Facts fill in when the second request finishes. With Web Search off, the Facts section says “Turn on Web Search in Settings to check facts.”
  • Fact checks never use the Corrections styling. A fact check offers “Use Wording” only when it came with a replacement, and the link opens the source in the browser.
