Introduction

Quill is a Mac app for writing and publishing on a self-hosted WordPress site. You write posts and pages in Quill, and it saves them to WordPress in the same block format the WordPress editor uses, so you can move between the two whenever you like.

Quill handles the writing: posts and pages, images and galleries, categories and tags, scheduling, and optional AI help through Anthropic's Claude API. Themes, plugins, comments, users and site layout stay in the WordPress admin.

Quill is free to use. It is not open source; the terms are in the license.

Requirements and Installation

Requirements

  • A Mac with Apple silicon running macOS 27 (Golden Gate) or later. Quill won't launch on earlier versions of macOS or on Intel Macs.
  • A self-hosted WordPress site running WordPress 7.0 or later, reachable over HTTPS. Older versions of WordPress may work, but they aren't supported.

Installing Quill

Download Quill from quill.siolon.com, unzip it, and drag Quill.app into your Applications folder.

Quill is notarized by Apple. The first time you open it, macOS asks you to confirm that you want to open an app downloaded from the internet. Click Open. You only see this once.

Updates

Quill checks for a new version each time it launches. When there is one, a Quill version available link appears at the top of the sidebar list. Click it to open the release page on GitHub, or click × to hide the notice for that version.

To update, download the new version, unzip it, and replace Quill.app in your Applications folder. Your credentials, drafts and settings are stored separately and carry over.

Help → Changelog lists what changed in each release. Help → User Guide opens this page.

Connecting to WordPress

Quill signs in to WordPress with an application password: a password WordPress generates for a single app, which you can revoke at any time without changing your account password. You need three things: your site's address, your WordPress username, and an application password.

Step 1: Create an Application Password

  1. Log in to your WordPress admin.
  2. Go to Users → Profile.
  3. Scroll down to Application Passwords.
  4. In New Application Password Name, type a name you'll recognize, such as "Quill".
  5. Click Add New Application Password.
  6. Copy the password WordPress shows you. WordPress won't show it again.

Step 2: Add It to Quill

  1. Choose Quill → Settings (⌘,).
  2. Under WordPress Credentials, fill in:
    • Site URL: your site's full address, starting with https:// (for example, https://example.com). Plain http:// is accepted only for a site running on localhost.
    • Username: your WordPress username.
    • Application Password: the password from step 1.
  3. Click Save.

Quill tries the credentials against your site before it saves them. If the test fails, the error appears in the Settings window and nothing is saved. Once they're accepted, your posts and pages load in the sidebar.

Credentials are stored in a file on your Mac that only your user account can read, not in the system keychain, so Quill never asks for your Mac password.

If Quill Can't Load Your Site

When a section fails to load, the sidebar shows the error with an Open Blog Settings… button, and the editor area reads "Couldn't load posts" (or pages, or media). Check your credentials in Settings, then press ⌘R to try again. Local drafts are stored on your Mac, so the Drafts section keeps working while your site is unreachable.

If the error says WordPress sent a reply Quill couldn't read, something on your site is adding text to its API responses, usually a PHP warning or notice from a plugin or theme. Fix or disable whichever one is producing it.

Quill's Interface

The Quill window has three parts: the sidebar on the left, the editor in the middle, and an inspector on the right. The inspector shows post settings while you're editing, or file details in the media library. You can hide the sidebar and the inspector separately.

The Sidebar

Four buttons at the top of the sidebar switch between its sections:

  • Posts and Pages list everything in that section of your site, including drafts, scheduled, pending and private items, newest first.
  • Drafts lists local drafts: posts and pages that exist only on your Mac and haven't been sent to WordPress yet. They're available even when your site isn't.
  • Media turns the sidebar into a list of filters (All Media, Images, Documents, Audio, Video) and shows your media library as a grid in the main area.

The search field below the section buttons filters the current list by title. In Media, it searches the library by file name and title.

Click an item to open it. To remove one, right-click it:

  • Move to Trash sends a post or page to the WordPress trash, where you can restore it from the WordPress admin.
  • Delete Draft deletes a local draft permanently. Local drafts have no trash.

The sidebar button at the left end of the window toolbar hides and shows the sidebar.

When Nothing Is Open

With no item selected, the editor area reads "Select a post to edit" (or page, or draft). Start something new from the File menu, the + menu, or with the shortcuts in the next section.

Writing and Editing

Creating Posts and Pages

Use the File menu or the + menu in the window toolbar:

  • New Post (⌘N)
  • New Page (⇧⌘N)
  • New Media (⌥⌘N), called Upload Media in the + menu

A new post or page starts as a local draft in the Drafts section. It stays on your Mac until you send it to WordPress.

Type the title in the Title field at the top of the editor, and the body below it. Headings, lists, quotes and other blocks show their formatting as you write. Your theme's fonts and colours apply only on the published site.

Links

Select some text and click the Link button to open the link picker. Start typing to search your site's posts, pages, categories, tags and media by title, or paste any URL. Click a result or press Return to apply it. With the cursor on an existing link, the picker also has a Remove link button.

To follow a link from the editor, hold ⌘ and click it. Links show an underline and a pointing-hand cursor while ⌘ is held down.

A link opens in the same tab unless you turn on New tab in the second toolbar row.

Markdown Shortcuts

The editor turns common Markdown into formatting as you type.

Blocks

Type these at the start of an empty line:

Type thisTo get
# through ###### Heading 1 through Heading 6
- or * or + Bulleted list
1. Numbered list
5. Numbered list starting at 5 (any number works)
> Quote
``` and a spaceCode block
```js and a spaceCode block with a language set (js, python and so on)
---Separator
*** or ___ Separator

--- converts as soon as you type the third hyphen. *** and ___ need a space after them.

Inline Formatting

These convert as soon as you type the closing characters:

Type thisTo get
**bold** or __bold__Bold
*italic* or _italic_Italic
~~strikethrough~~Strikethrough
`code`Inline code

Markdown has no underline, so use ⌘U.

Automatic Links

A web address becomes a link when you type a space after it. This works for full URLs (https://example.com), addresses starting with www., and email addresses.

What Doesn't Convert

  • 1) doesn't start a numbered list. Use 1.
  • - [ ] doesn't make a checklist, because Quill has no checklist block.
  • ==highlight== stays as typed.
  • Quill doesn't change punctuation as you type: -- stays two hyphens, ... stays three dots, and straight quotes stay straight. Type or paste typographic characters if you want them.

Undoing a Conversion

If a shortcut converts something you wanted to keep as typed, press Delete straight away. The formatting is removed and your characters come back, so # stays # and **bold** stays **bold**. Code blocks are the exception: Delete removes the block but not the backticks.

This only works as the very next key you press. After that, Delete behaves normally, and ⌘Z undoes the conversion along with the typing around it.

Pasting

What you get when you paste depends on what's on the clipboard. Text copied from a web page, a word processor or a chat app carries formatting, and ⌘V handles it. Plain-text Markdown needs its own command.

Formatted Text (⌘V)

Quill rebuilds pasted content with its own formatting instead of keeping the original markup, so you don't inherit another app's fonts, colours or stray code. Text pasted from Word or Google Docs matches the rest of your post.

Headings, paragraphs, lists (nested ones too), quotes, tables, images, links and inline formatting all come through, along with any classes and IDs already on them. Blocks copied from another WordPress site's editor are kept exactly as they were.

Some things are dropped without any warning:

PastedResult
<iframe>, <video>, <audio>Removed. Nothing is inserted
Definition listsTurned into ordinary paragraphs

The one most likely to catch you out is a YouTube <iframe> copied from a page's source, which inserts nothing. Use the Embed button with the video's URL instead (see Embeds). After a large paste, it's worth a look in code view to confirm everything arrived.

Markdown (⇧⌘V)

The Markdown Shortcuts only work on text you type. If you paste Markdown with ⌘V, most of it arrives as plain characters, so # Heading stays # Heading. A few pieces, such as **bold** and `code`, do convert, which leaves the text half formatted.

Choose Edit → Paste as Markdown (⇧⌘V) instead. It converts everything on the clipboard at once and inserts it at the cursor: headings, lists, quotes, tables, code blocks, separators, links and inline formatting.

  • ⌘V is unaffected. Paste as Markdown is a separate command.
  • Text copied from a web page or chat app usually pastes better with ⌘V, because it's already formatted.
  • A Markdown image (![alt](url)) keeps its original address, so the published post would load it from wherever it lives now. Replace it with an image uploaded to your media library.
  • The command doesn't work inside footnotes, code blocks or code view. Quill explains why and inserts nothing.
  • Checklist items (- [ ]) become ordinary list items.

Saving and Publishing

Local Drafts

Click Save Draft or press ⌘S to save a local draft on your Mac. Nothing is sent to WordPress.

To send a local draft to WordPress, choose a Status in Post Settings, then click the publish button or press ⇧⌘P. The button's name tells you what will happen. A new draft's status is Draft, so the button reads Publish Draft and creates a draft on WordPress. Set the status to Published first if you want it to go live straight away.

Once the draft is on WordPress, it moves from Drafts to Posts or Pages.

Posts and Pages on WordPress

⌘S and the publish button both save your changes to WordPress with the post's current status. On a published post, the button reads Update.

Revert throws away your unsaved changes and reloads the post from WordPress. Quill asks you to confirm first.

Before saving, Quill checks whether the post has been changed on WordPress since you opened it, for example in the WordPress editor. If it has, a Conflict Detected alert gives you three choices: Keep Local saves your version over the one on WordPress, Use Server throws away your changes and loads the WordPress version, and Cancel does nothing.

Autosave

Quill saves your work on your Mac 30 seconds after your last change, and again when you switch to another item. For a local draft, this updates the draft. For a post on WordPress, the autosave stays on your Mac and nothing is sent to your site. If you reopen the post before saving it to WordPress, even after quitting Quill, your changes come back and Quill shows "Unsaved changes restored".

Preview

Click Preview to see the post in your browser the way it looks on your site. Preview works only for posts and pages already on WordPress, not for local drafts.

For a published post, Quill sends your unsaved changes to WordPress as a temporary revision. Only the preview shows them; the live post doesn't change.

For a draft, WordPress saves your changes into the draft itself, because drafts don't keep a separate preview copy. Previewing a draft is the same as saving it to WordPress.

Find and Replace

Press ⌘F (or choose Edit → Find…) to open the find bar. Type in Find to highlight every match. Press Return for the next match and ⇧Return for the previous one, or use the arrow buttons. Turn on Aa to match upper and lower case exactly.

To replace text, type the new text in Replace, then click Replace for the current match or All for every match. Press Esc or click ✕ to close the bar.

Spell Check

Click ABC in the toolbar to check spelling. Misspelled words get a red underline. Right-click an underlined word to pick a suggestion. Editing a word removes its underline; click ABC again to check the post again.

Code View

Click </> in the toolbar to switch between the visual editor and the post's HTML. Code view shows exactly what Quill saves to WordPress, including the block comments such as <!-- wp:paragraph -->, indented so it's easy to read. Click </> again to return to the visual editor.

Editing in code view. You can type straight into the HTML. Quill picks up your changes as you type, so ⌘S saves what's in code view without you having to leave it first.

Classes and IDs. A class or ID you add in code view stays put when you go back to the visual editor and keep writing, on any of these:

  • Paragraphs, headings, quotes and citations
  • Lists (<ul>, <ol>, <li>)
  • Code blocks and separators
  • Tables (<table>, <tr>, <th>, <td>)
  • Image figures (<figure>) and images (<img>)
  • Links (<a>)

For example, if you add class="intro" to a paragraph, switch back and type more, the class is still there. Changing a link's address in the link picker keeps any classes on it. Pressing Return to start a new block doesn't copy classes to it.

Other HTML changes. Anything else you change in code view, such as inline styles, data attributes or custom elements, is saved exactly as you wrote it as long as you save before making changes in the visual editor. Once you edit in the visual editor, Quill rebuilds the HTML from what the editor understands, and those changes are lost.

Blocks Quill can't edit. A block Quill has no editor for, such as Audio, Video, Playlist, Cover, Group, Media & Text, Spacer, Custom HTML or a plugin's block, appears in the visual editor as a card with the block's name and the note "Not editable in the visual editor; use Code View (</>)". The card keeps the block's markup exactly as it was, including anything nested inside, and edits elsewhere in the post don't touch it. It's lost only if you delete the card. To change what's in the block, use code view.

Protecting your own HTML. A custom element you write in code view without a wp-block- class, such as a callout box, is reduced to plain text as soon as you edit in the visual editor. To keep it, add any class that starts with wp-block- (for example wp-block-group) alongside your own. Quill then treats it like a block it can't edit: it shows as a card, keeps its markup, and you can still change it in code view.

If you need changes that go beyond classes on the elements listed above, do your writing in the visual editor first and make the HTML changes in code view last, just before you save.

Content Elements

Images

Click Image in the toolbar to open your media library, then click an image to insert it at the cursor. Upload… in the same window adds an image from your Mac to the library first.

You can also drag image files from the Finder onto the editor. Quill uploads them to your media library and inserts them. A progress indicator at the bottom of the window counts through a batch ("Uploading image 2 of 3…") and finishes with one message, such as "3 images inserted". If something goes wrong, the message names the problem, or says how many files in the batch failed. You can drop another batch before the first one finishes; Quill uploads them in turn.

HEIC photos, the format iPhones use by default, are converted to JPEG before upload so WordPress can make its usual smaller sizes (see Uploading).

After an image goes in, the cursor moves to a new empty paragraph below it so you can keep typing. Click the image to select it. An image toolbar appears over it, and the alignment and Style controls appear in the second toolbar row.

Size

  • Drag any of the eight handles around a selected image to resize it.
  • Type exact pixel sizes in the W and H fields in the image toolbar.
  • For images from your media library, Thumb, Medium, Large and Full jump to the sizes WordPress made for that image. Images from elsewhere only have the W and H fields.
  • Reset returns the image to its original full size.

Alt Text

Type a description in the Alt field in the image toolbar. Screen readers read it out, and search engines use it. If the image already has alt text in the media library, Quill fills it in when you insert the image.

An image marked as decorative in the WordPress editor stays marked that way when you edit and save in Quill. Quill has no control for this setting, and it doesn't add or remove it.

Alignment

With an image selected, the left, center and right buttons in the second toolbar row float it to one side with text wrapping around it, or center it.

Captions

A caption is optional. To add one, click the space just below the image and type. Press Return to leave the caption and start a new paragraph. Because the cursor lands below the image after you insert it, typing straight away adds body text, not a caption.

Linking to the Full-Size Image

Click Link to Full Image in the image toolbar to make the image a link to its original, full-size file. Readers who click it on your site see (or download) the full-size version. Click the button again to remove the link. This works whatever size the image is shown at in the post.

Galleries

Click Gallery in the toolbar to open the gallery picker. Click images in the grid to select them. Each one gets a checkmark and is added to the Selected list, in the order it will appear. Drag an image in that list by its handle to move it, or click its ✕ to take it out.

Click the arrow next to a selected image to give it Alt Text and a Caption. Alt text from the media library is filled in for you. What you type here applies only to this gallery. The image in your media library, and any other post that uses it, isn't changed.

Upload… adds an image from your Mac to your media library and selects it.

The gallery settings are below the Selected list:

  • Columns: how many images per row, from 1 to 8.
  • Crop: turn on Square to crop every image to a square.
  • Link To: None, or Full Image to make each image a link to its full-size file.
  • Size: which of WordPress's image sizes to use: Thumbnail, Medium, Large or Full Size.
About Size: WordPress usually offers the browser several sizes of each image and lets it choose, which is what keeps photos sharp on Retina screens. On a modern high-resolution display you may see no difference between Medium and Large for that reason. Size still matters in older browsers, RSS feeds and email, and it always changes how much data the page loads.

Click Insert Gallery to add the gallery as a single block. The button is available once at least one image is selected.

In the editor, a gallery shows as a grid of thumbnails that you can't edit directly. To change one, including its alt text and captions, delete it and insert a new one, or edit its markup in code view. Galleries made in the WordPress editor load the same way, and their captions and other details are kept when you edit the rest of the post.

Quotes

Press ⇧⌘B or click Blockquote to turn the current block into a quote. Do the same again to turn it back into ordinary paragraphs.

Inside a quote, the second toolbar row has a Cite button. Click it to add a line at the bottom of the quote for the author or source, and click it again to remove the line. An empty citation isn't saved.

Pressing Return inside a quote starts a new paragraph in the quote. Pressing Return on an empty line leaves the quote.

A Pullquote is a separate block for a quote that stands apart from the text around it. Insert it from the + menu. It gets a citation from the same Cite button.

Container Blocks

Columns, Details, Buttons, Accordion, Tabs, Pullquote and Preformatted are blocks that hold other content. Insert them from the + menu in the toolbar, then type in them as you would anywhere else.

BlockWhat it is
ColumnsContent in side-by-side columns
DetailsA section that opens and closes when the reader clicks its summary line
ButtonsOne or more buttons that link somewhere
AccordionA stack of sections that open and close, each with its own heading
TabsPanels with a row of tabs, showing one panel at a time
PullquoteA quote set apart from the body text
PreformattedText kept exactly as typed, including spaces and line breaks

The controls for adding and removing columns, buttons, accordion sections and tabs are in the second toolbar row, along with each block's settings.

A new Accordion or Details block starts without a title. Quill shows a grey hint where the title goes, which appears only in the editor, never on your site. Click the hint to type the title.

To see how an accordion section or a Details block looks closed, click its heading row outside the title text. This only affects the editor. Whether it starts open on your site is the Open setting. In a Tabs block, the panel you see follows the cursor; the Default setting decides which tab readers see first.

Leaving a block. Press Esc to move the cursor to the paragraph below the block. Quill adds a paragraph if there isn't one. Pressing Return twice does the same. In nested blocks, each press moves out one level. This is how you carry on writing after a block at the end of a post.

Deleting a block. With the cursor in a block, a ✕ appears at the right end of the second toolbar row, with a tooltip naming the block it will delete. Click it or press ⇧⌘⌫. This works for tables, quotes, pullquotes, code blocks, preformatted text, separators and the container blocks. The cursor moves to the next block, or to the one before if there's nothing after it. In nested blocks, the innermost one goes first, so you can work outwards one block at a time.

Separators

A separator is a horizontal line between sections. Insert one from the + menu, or type --- on an empty line. Click it to select it; ✕ or ⇧⌘⌫ deletes it. Its style, a wide line or a row of dots, is in the second toolbar row.

Footnotes

Put the cursor where you want the footnote number and click * in the toolbar. A numbered marker appears at the cursor, and a matching note is added to the list at the bottom of the post for you to type into.

  • Footnotes are numbered in the order they appear. Adding one between two others, or deleting one, renumbers the rest.
  • The ↩︎ button after each note takes you back to its marker in the text.
  • To delete a footnote, delete its marker. The note goes with it. You can't delete a note from the list on its own.
  • Press Return inside a note to start a new line in the same note.
  • Notes can hold bold, italic, strikethrough, inline code and links, but not images, headings, lists, tables or quotes. Those toolbar buttons are turned off while the cursor is in a note, and pasting into a note keeps only the text and inline formatting.

Quill saves footnotes the way current WordPress does, with the note text stored alongside the post rather than in its body. On your site they look exactly as they would from the WordPress editor.

Footnotes written by older versions of Quill were stored differently. Quill leaves such a post as it is until you edit it, and the first edit moves the notes to the current format. Nothing is lost either way.

Tables

Click Table in the toolbar to open a size grid. As you move across it, the label reads back the size, so "4×3 Table" is four columns by three rows. Click to insert. You can also use the arrow keys, Return to insert and Esc to close.

A new table has a header row, saved as a proper table header on your site. With the cursor in a table, the second toolbar row has:

ButtonWhat it does
+RowAdds a row below the current one
+ColAdds a column to the right of the current one
−RowDeletes the current row
−ColDeletes the current column

FooterTurns the footer row on or off

Press Tab to move to the next cell and ⇧Tab to move back. Tab in the last cell adds a new row. To delete the whole table, click ✕ at the end of the second row or press ⇧⌘⌫.

A table from WordPress keeps whatever header and footer rows it had. A table caption written in the WordPress editor is kept as it is, but Quill can't add or change captions; do that in WordPress.

Embeds

Embeds put a video, social post or audio player from another site into your post.

  1. Click Embed in the toolbar.
  2. Paste the URL of what you want to embed.
  3. Press Return or click Insert.

In the editor, an embed shows as a card with the provider's name and the URL. The embed itself appears only on your published site; Quill doesn't load it.

Quill recognizes these providers and saves them the way the WordPress editor does:

YouTubeVideo
VimeoVideo

Other URLs are saved as general embeds, and WordPress tries to show them with its own embed support.

Whether an embed shows correctly on your site depends on the provider, and providers change their embed support without notice. X embeds are known to be unreliable.

Post and Page Settings

Click Post Settings at the right end of the window toolbar to open the settings inspector for the current post or page. The AI evaluation uses the same space, so opening one replaces the other.

Changes here are sent to WordPress the next time you save or publish, not as you make them.

Settings for a local draft are sent to WordPress when you publish it, but they aren't saved with the draft. If you switch to another item or quit Quill before publishing, you'll need to set them again. The excerpt is the exception: it's saved with the draft.

Status controls whether and when the post is visible on your site:

Publish Date

The Publish Date section appears for every status except Private. Turn on Schedule to set the status to Scheduled and show a date and time picker, set to an hour from now. Turn it off to go back to Draft.

Choosing Scheduled in the Status menu does the same thing.

When the date and time are right, click the publish button, which now reads Schedule, or press ⇧⌘P. WordPress publishes the post at that time.

Categories (Posts only)

Every category on your site is listed here in alphabetical order. Tick a category to assign it; ticked categories move to the top of the list. Type in the field above the list to filter it.

To add a new category, type its name and press Return, or click Add "name". It's marked "new" and is created on your site when you save or publish the post.

Tags (Posts only)

Tags assigned to the post appear above the search field; click the × on one to remove it. Type to find an existing tag and click it to add it, or press Return to create a new tag. New tags are created on your site when you save or publish the post.

Slug

The slug is the part of the post's web address that comes from its title, such as my-first-post. Change it here, or leave it blank and WordPress makes one from the title.

Excerpt (Posts only)

An excerpt is a short summary that some themes show on archive and search pages. If you leave it blank, your theme may show the opening words of the post there instead.

Parent Page (Pages only)

Choose a parent to put this page under another one in your site's structure and web address, or leave it at None (top-level).

Discussion

Turn off Allow comments to close comments on the post or page.

Stats

A live word and character count for the post, with an estimated reading time based on 238 words a minute, rounded up.

Media Library

Click Media at the top of the sidebar to browse everything uploaded to your site. The sidebar shows a list of filters and the library fills the main area as a grid, newest first.

Browsing

Images show as thumbnails, and other files show a file icon. Click an item to select it, and use the arrow keys to move the selection. More items load as you scroll.

The filters narrow the grid to one kind of file. Documents covers PDFs and office files. Plain-text files such as .txt and .csv aren't included there; you'll find them under All Media. The search field searches within the current filter, so if a file you expect is missing, clear the search or switch to All Media.

Right-click an item for these commands:

Previewing

Press Space or double-click an item to see a large preview over the grid. Press Space or Esc again, or click outside the preview, to close it. Only images can be previewed; other files show a placeholder.

Details

To see an item's details, click Media Info at the right end of the window toolbar, or right-click the item and choose Show Details. The inspector opens on the right and follows whichever item is selected until you close it.

Uploading

Choose Upload Media from the + menu, or File → New Media (⌥⌘N) from anywhere in Quill. Pick a file in the window that opens. You can upload any file type your WordPress site allows.

The new item appears at the top of the grid, already selected. If the current filter wouldn't show it, for example a PDF uploaded while Images is selected, Quill switches to All Media so it's still in view.

HEIC photos are converted to JPEG before they're uploaded. WordPress accepts HEIC files but can't make thumbnails or other sizes from them, so an unconverted HEIC would sit in your library with no dimensions and no smaller versions. The conversion happens on your Mac, keeps the photo's full resolution and orientation, and leaves your original file alone. It applies to every way of uploading: the Media section, the image picker, the gallery picker and dragging onto the editor. Other formats, such as JPEG, PNG, GIF, WebP and PDF, are uploaded as they are.

Deleting Media

Right-click an item and choose Delete…. Quill asks you to confirm first.

Deleting media is permanent. WordPress has no trash for media, so a deleted file can't be recovered.

AI Writing Features

Quill can use Anthropic's Claude API, with the Claude Haiku model, to write posts, rewrite selected text and review your writing. These features are off until you add your own Anthropic API key, and Anthropic bills you directly for what you use.

Setting Up

  1. Create an API key at platform.claude.com/dashboard.
  2. Choose Quill → Settings (⌘,) and find the AI Writing section.
  3. Paste the key into Anthropic API Key and click Save.

Once a key is saved, the Generate (pencil) and Evaluate (checkmark) buttons appear in the editor toolbar. Quill doesn't test the key when you save it; a wrong key shows up as an error the first time you use a feature.

Writing Style

Quill can learn how you write from your own posts. In the AI Writing section of Settings, click Choose Posts and pick up to five posts that sound like you. When you click Save, Quill sends them to Claude, which writes a short style guide. Quill uses that guide whenever it writes or reviews for you.

The guide is rewritten whenever you change which posts you picked. If you connect Quill to a different WordPress site, your picks are cleared and you'll need to choose again.

Web Search

With Web Search turned on in Settings, Claude can search the web for current information while writing a post. It's on to begin with. Turn it off to write from Claude's own knowledge only, which is faster and costs less.

Generating a Post

Click the pencil button in the toolbar. Describe what you want, anything from a topic to a detailed brief, and click Generate (⌘Return). Quill writes a complete post or page with a title and loads it into the editor. With web search on, Claude looks up the topic before writing.

If the editor already has content, a Replace Content? alert asks you to confirm first, because the new post replaces your title and text.

If a long post hits the first length limit, a Post may be cut off alert appears. Get Full Version asks for a longer response, which costs more. Use What I Have keeps what was written.

Evaluating Your Writing

Click the checkmark button in the toolbar to have Claude review the current post or page. It needs at least 100 words; with fewer, the panel asks you to add more.

The results open in the inspector on the right, in place of Post Settings. They include a short summary and a list of findings. Each finding has a category (Grammar, Clarity, Readability, Wordiness, Passive Voice or Tone) and sometimes a suggested rewrite.

  • Click a finding to select that sentence in the editor and scroll to it.
  • Click Re-evaluate at the bottom of the panel to run the review again after you've made changes.
  • If you've set up a writing style, Claude takes it into account and doesn't flag choices that match how you normally write.

The checkmark button is highlighted while the results are open, and turned off while a review is running. The panel has no close button: click Post Settings in the window toolbar to close the inspector, and click it again to get your settings back.

Rewriting a Selection

Select at least ten characters of text, right-click the selection, and choose one of these:

CommandWhat it does
Make LongerAdds supporting detail. A short passage grows to about four times its length; a long one to about one and a half times
Make ShorterCuts the least important sentences and tightens the rest. A short passage shrinks to about 70% of its length; a long one to about 40%
Convert to TableTurns the selection into a table
Convert to ListTurns the selection into a bulleted or numbered list

Make Longer and Make Shorter keep the same number of paragraphs. They don't add headings or lists, and they don't merge paragraphs. When the selection is in a list or table, they lengthen or shorten each item or cell and keep the list or table intact.

These commands change only the selected text and never use web search. They don't appear inside footnotes.

The new text replaces your selection, highlighted, and an Accept / Discard bar appears at the bottom of the editor. Click Accept or press Return to keep it. Click Discard, press Esc or click anywhere else to put your original text back. If Claude sends back nothing usable, your text stays as it was and an error message appears.

Limitations and Compatibility

WordPress.com

Quill works only with self-hosted WordPress. WordPress.com sites aren't supported.

One Site at a Time

Quill connects to one WordPress site. To switch to another, change the credentials in Settings.

When Quill Can't Keep Something

Each time Quill opens a post, and each time you leave code view, it checks that every block in the post is still there in the editor. If any are missing, a red banner at the top of the editor names them, and saving is blocked until you respond. Saving at that point would write the shortened post over the real one.

When you see the banner:

  1. Check which blocks it names.
  2. If you need them, don't save. Nothing has been written yet. Close the post and edit it in the WordPress editor instead.
  3. To fix it in Quill, open code view (</>) and paste the missing block's markup back in. When you leave code view, the banner goes away and you can save again.
  4. If you don't mind losing them, click Save anyway, I understand and save. Afterwards, the banner tells you what was removed and reminds you that WordPress's revision history still has the earlier version.

If you open a post like this and don't edit it, saving is never blocked. Quill sends the original content back unchanged, so nothing can be lost. Once you've saved a post with missing blocks, reopening it shows no banner, because the blocks are no longer in the saved post.

You should rarely see this banner. Quill normally keeps blocks it can't edit exactly as they were (see below).

Block Editor Compatibility

Quill saves posts in the same block format as the WordPress editor for everything it can edit: paragraphs, headings, lists, quotes, code blocks, separators, images, galleries, tables, embeds, footnotes, links, and the container blocks (Columns, Details, Buttons, Accordion, Tabs, Pullquote and Preformatted). A post written in Quill opens in the WordPress editor as separate blocks, and you can go back and forth between the two.

Settings you chose in WordPress are kept. A colour, a font size, a border radius, a block style, a link that opens in a new tab, a table's fixed layout: Quill keeps all of these through an edit even when it has no control for them, and saves them back the way WordPress wrote them.

Blocks Quill can't edit, including Audio, Video, Playlist, Cover, Group, Media & Text, Spacer, Custom HTML, shortcodes and plugin blocks, appear in the editor as cards showing a short preview of their code. You can move or delete a card and edit the rest of the post freely; the block is saved back to WordPress exactly as it arrived. To change what's inside one, use code view or the WordPress editor.

Classic posts are converted when you edit them. A post written before the block editor existed has no blocks. If you open one and save without changing anything, it's left alone. Once you make an edit, Quill converts it to blocks, the same way WordPress's "Convert to blocks" does. Paragraphs, headings and lists come through fine, but a plain wrapper <div> with a custom class doesn't survive. If a classic post relies on markup like that, edit it in the WordPress editor.

Galleries can be inserted but not edited. To change a gallery, delete it and insert a new one.

Featured Images

Quill keeps a post's featured image when you save, but it has no way to set or change one. Use the WordPress admin for that.

What Quill Doesn't Do

These stay in the WordPress admin:

  • Themes and site customization
  • Plugins
  • Comment moderation
  • Users and roles
  • Revision history
  • Image editing, such as cropping or rotating
